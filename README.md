# 🎁 준비된 선물 (PresenTTo)

기념일, 받는 사람, 예산만 고르면 딱 맞는 선물 5개를 추천해 주는 Java Swing 프로그램입니다.

**발표 자료**: https://claude.ai/artifact/WnxhUwVhMCaJAYJSmieKw4

## 실행 방법
JDK 21 이상이 필요합니다.

```bash
javac -d out src/*.java
java -cp out Main
```

IntelliJ IDEA에서는 프로젝트를 열고 `Main`을 실행하면 됩니다.
창 크기는 1100×800으로, 13인치 노트북 화면에도 들어갑니다.

> **macOS에서 실행하는 것을 권장합니다.** 자세한 내용은 [참고](#참고)를 보세요.

## 사용 방법
1. **기념일**을 고릅니다.
2. **받는 사람**과 **예산**을 고릅니다.
3. 프로그램을 켜면 바로 선물 카드 5장이 나옵니다. **[다른 추천 보기]**를 누르면 고른 조건으로 다른 선물이 나옵니다.

## 화면 구성

```
┌────────────────────────────────────────────────────────────────┐
│ 🎁 준비된 선물   기념일과 받는 사람과 예산만 고르면 …            │  헤더 (그라데이션)
├────────────────────────────────────────────────────────────────┤
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ 📅 기념일    [생일] [커플 100일] … (7개 한 줄)              │ │
│ │ 👥 받는 사람 [친구] [연인] [부모님] … (5개 한 줄)            │ │  조건 고르기
│ │ 💰 예산      [1만원 이하] … [상관없음]                [추천] │ │
│ └────────────────────────────────────────────────────────────┘ │
│ 🎁 연인에게 주는 생일 선물 · 3만원 이하                          │  결과 제목
│ 응원 문구                                                        │
│ ┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐              │
│ │태그   │ │       │ │       │ │       │ │       │              │
│ │  🎂   │ │  💐   │ │  ☕   │ │  🎡   │ │  🧸   │              │  선물 카드 5장
│ │이름    │ │       │ │       │ │       │ │       │              │  (선물마다 다른 그림)
│ │추천 이유│ │  …    │ │  …    │ │  …    │ │  …    │              │
│ │설명    │ │       │ │       │ │       │ │       │              │

│ │가격    │ │       │ │       │ │       │ │       │              │
│ └───────┘ └───────┘ └───────┘ └───────┘ └───────┘              │
└────────────────────────────────────────────────────────────────┘
```

- 헤더는 코랄 → 복숭아색 그라데이션이고, 배경은 따뜻한 크림색입니다.
- 줄마다 선택된 칩 색이 다릅니다: 기념일은 **코랄**, 받는 사람은 **보라**, 예산은 **청록**.
- 선택 안 된 칩은 테두리 없이 연한 회색이라 화면에 선이 적고 여백이 넉넉합니다.
- 칩은 모두 같은 너비이고, 칩과 버튼은 같은 둥글기(`RADIUS = 10`)를 씁니다.

## 기능

### 조건 고르기
| 항목 | 선택지 |
| --- | --- |
| 기념일 (7종) | 생일 · 커플 100일 · 졸업·입학 · 어버이날 · 스승의날 · 빼빼로데이 · 크리스마스 |
| 받는 사람 (5종) | 친구 · 연인 · 부모님 · 형제자매 · 선생님 |
| 예산 | 1만원 이하 · 3만원 이하 · 5만원 이하 · 상관없음 |

### 추천 결과
- 선물 75종 중에서 최대 5개를 추천합니다.
- 카드 한 장에는 다음이 나옵니다.
  - 위쪽 그림 영역: 선물 종류 색을 연하게 칠한 배경, **선물마다 다른 그림(이모지, 예: 🎂 💐 ☕ 🎡)**, 종류 태그
  - 아래쪽: 이름, 추천 이유, 설명, 그리고 맨 아래 한 줄에 가격
  - 가격은 종류 색으로, 쉼표를 넣어 `25,000원`처럼 보여 줍니다. 모바일 선물은 `9,500원 (바로 전송)`처럼 보여 줍니다.
- **추천 이유** 예시: `연인 · 생일에 딱 맞아요`
- 기념일에 딱 맞는 선물이 5개가 안 되면 받는 사람에게 어울리는 다른 선물로 채웁니다. 이런 카드는 회색이고 **"이런 것도 있어요"** 태그가 붙습니다.
- 누를 때마다 순서를 섞어서 다른 선물이 나옵니다.
- 선생님께는 청탁금지법을 고려해 0원짜리 마음 선물만 추천합니다.

### 선물 종류
| 종류 (태그) | 카드 색 | 개수 | 예시 |
| --- | --- | --- | --- |
| 일반 선물 | 빨강 | 53 | 핸드크림, 텀블러, 꽃다발, 손목시계, 명함 지갑 |
| 마음 선물 | 초록 | 15 | 손편지, 롤링페이퍼, 감사 영상 편지, 직접 만든 도시락 |
| 모바일 선물 | 파랑 | 11 | 카페 쿠폰, 케이크 기프티콘, 백화점 상품권 |
| 체험 선물 | 보라 | 10 | 방탈출 카페, 향수 만들기 공방, 놀이공원 자유이용권 |

## 추천 방식
`GiftRecommender.recommend()`가 다음 순서로 선물을 고릅니다.

1. 예산을 넘거나 받는 사람에게 맞지 않는 선물은 뺍니다.
2. 남은 선물을 두 그룹으로 나눕니다.
   - **1순위**: 고른 기념일에 맞는 선물
   - **2순위**: 기념일은 다르지만 받는 사람과 예산이 맞는 선물
3. 그룹 안에서 순서를 섞습니다.
4. 1순위부터 앞에서 5개를 고릅니다. 개수는 `GiftRecommender.COUNT`로 정합니다.

## 클래스 구조

```
Gift (일반 선물)
 ├─ HandmadeGift   (마음 선물)
 ├─ GifticonGift   (모바일 선물)
 └─ ExperienceGift (체험 선물)

Anniversary (추상 클래스)
 └─ Birthday, Couple100Days, Christmas … (기념일 7종)


Main ─ 사용 ─▶ GiftRecommender
```

| 클래스 | 설명 |
| --- | --- |
| `Main` | 프로그램 시작점이자 화면입니다. `JFrame`을 상속하고 `ActionListener`를 구현합니다. 아래 화면 부품 클래스도 안에 있습니다. |
| `GiftRecommender` | 선물 75종 목록을 가지고 있고, 조건에 맞는 선물을 골라 줍니다. |
| `Gift` | 선물 한 개의 정보(그림 이모지, 이름, 가격, 설명, 어울리는 기념일과 받는 사람)를 담습니다. 추천 이유, 태그, 카드 색을 알려 줍니다. |
| `HandmadeGift` | 0원짜리 마음 선물입니다. 가격 글자, 태그, 색을 오버라이딩합니다. |
| `GifticonGift` | 모바일 선물입니다. `super.getPriceText()` 뒤에 "(바로 전송)"을 붙이고, 태그와 색을 오버라이딩합니다. |
| `ExperienceGift` | 체험 선물입니다. 가격 글자는 부모 것을 그대로 쓰고, 태그와 색을 오버라이딩합니다. |
| `Anniversary` | 기념일 추상 클래스입니다. 이름과 응원 문구(추상 메소드)를 가집니다. |
| `Anniversaries` | 기념일 7종을 만들어 `Anniversary[]`로 돌려줍니다. 각 기념일 자식 클래스도 이 파일에 있습니다. |

### 화면 부품 (`Main` 안의 클래스)
Swing 기본 부품을 상속하고 `paintComponent()`를 오버라이딩해서 직접 그렸습니다.

| 클래스 | 상속 | 역할 |
| --- | --- | --- |
| `RoundPanel` | `JPanel` | 둥근 상자. 조건 상자, 카드, 카드 위쪽 그림 영역에 씁니다. |
| `RoundButton` | `JButton` | 둥근 코랄 버튼 (다른 추천 보기). 마우스를 올리면 조금 진해집니다. |
| `Chip` | `JToggleButton` | 선택 칩. 줄마다 선택 색이 다릅니다. |
| `EmojiPicture` | `JComponent` | 선물 그림(이모지). 맥 자바는 100px보다 큰 컬러 이모지를 못 그려서, 96px 그림으로 한 번 만든 뒤 크기를 바꿔 그립니다. (레티나 화면 대응) |
| `Header` | `JPanel` | 맨 위 그라데이션 제목 띠 |

## 객체지향 개념이 쓰인 곳
| 개념 | 어디에 |
| --- | --- |
| **캡슐화** | `Gift`의 필드는 모두 `private`이고 getter와 메소드로만 다룹니다. |
| **상속** | `Gift`를 상속한 선물 3종, `Anniversary`를 상속한 기념일 7종, `Main extends JFrame` |
| **추상 클래스** | `Anniversary`. `getMessage()`는 추상 메소드라 자식이 꼭 구현합니다. |
| **오버라이딩** | 선물 종류마다 `getTag()`, `getColor()`, `getPriceText()`를 다르게 구현합니다. 기념일마다 `getMessage()`를 다르게 구현합니다. 화면 부품은 `paintComponent()`를 오버라이딩해서 직접 그립니다. |
| **다형성** | `Main`은 `Gift`와 `Anniversary` 타입으로만 다룹니다. if문 없이 `gift.getColor()`나 `anniversary.getMessage()`를 부르면 객체에 맞는 결과가 나옵니다. |
| **인터페이스** | `ActionListener`로 버튼 클릭을 처리합니다. |

## 참고
- **규모**: 자바 파일 8개, 선물 75가지, 기념일 7가지, 받는 사람 5가지
- **macOS 권장**: 글꼴(Apple SD Gothic Neo)과 선물 그림(Apple Color Emoji)이 맥 기준입니다. 윈도우에서는 선물 그림이 네모로 보일 수 있습니다.
- **레티나 화면 대응**: 맥 자바는 100px보다 큰 컬러 이모지를 빈칸으로 그립니다. 레티나 화면은 2배로 그려서 카드 그림이 사라지기 때문에, `EmojiPicture`가 이모지를 96px 그림으로 한 번 만든 뒤 줄여서 그립니다.
- **선물 추가 방법**: `GiftRecommender` 생성자에 한 줄을 넣으면 됩니다.
  ```java
  // 그림, 이름, 가격, 설명, 어울리는 기념일, 어울리는 받는 사람
  gifts.add(new Gift("🧦", "양말 세트", 9000, "귀여운 무늬 양말로 가볍게 마음 전하기",
          new String[]{"생일"}, new String[]{"친구", "연인"}));
  ```
- **기념일 추가 방법**: `Anniversary`를 상속하고 `getMessage()`를 오버라이딩한 클래스를 만들고 `Anniversaries.getAll()`에 넣으면 됩니다.
