# 🎁 준비된 선물 (PresenTTo)

기념일, 받는 사람, 예산만 고르면 딱 맞는 선물 3개를 추천해 주는 Java Swing 프로그램입니다.

## 기능
- 기념일 선택: 생일 / 커플 100일 / 발렌타인데이 / 화이트데이 / 어버이날 / 스승의날 / 빼빼로데이 / 크리스마스 (칩 아래에 날짜와 D-day 표시, 가장 가까운 기념일을 기본 선택)
- 받는 사람 선택: 친구 / 연인 / 부모님 / 조부모님 / 형제자매 / 선생님
- 예산 선택: 1만원 이하 / 3만원 이하 / 5만원 이하 / 상관없음 / 직접 입력 (예: 25000, 3만원, 2만5000 — 잘못 입력하면 이유를 알려 줌)
- 조건에 맞는 선물을 최대 3개 추천 (누를 때마다 다른 결과)
- 기념일에 딱 맞는 선물이 부족하면 다른 선물로 채우고 "이런 것도 있어요" 태그로 구분
- 카드마다 추천 이유 한 줄 표시 (예: "연인 · 생일에 딱 맞아요")
- 결과 정렬: 랜덤 / 가격 낮은 순 / 가격 높은 순 (`Gift`가 `Comparable` 구현)
- 카드의 하트로 찜하기, [찜 목록]에서 찜한 선물과 총액 확인 / 빼기
- 선물 종류별 카드 색 구분: 일반 선물(빨강) / 마음 선물(초록) / 모바일 선물(파랑)
- 선생님께는 청탁금지법을 고려해 0원짜리 마음 선물만 추천

## 실행 방법
JDK 21 이상이 필요합니다.

```bash
javac -d out src/*.java
java -cp out Main
```

IntelliJ IDEA에서는 프로젝트를 열고 `Main`을 실행하면 됩니다.

## 클래스 구조
| 클래스 | 설명 |
| --- | --- |
| `Gift` | 선물 한 개의 정보 (캡슐화) |
| `HandmadeGift` | `Gift`를 상속한 0원짜리 마음 선물, 초록 카드 (오버라이딩) |
| `GifticonGift` | `Gift`를 상속한 모바일 선물(기프티콘), 파란 카드 (오버라이딩) |
| `Anniversary` | 기념일 추상 클래스 (이름 + 날짜) |
| `Anniversaries` | 기념일 8종 자식 클래스 (다형성) |
| `Wishlist` | 찜한 선물 목록과 총액 계산 (캡슐화) |
| `BudgetException` | 예산을 잘못 입력했을 때 던지는 직접 만든 예외 (`Exception` 상속) |
| `GiftRecommender` | 선물 목록과 추천 로직 |
| `Main` | Swing 화면과 버튼 처리 |
