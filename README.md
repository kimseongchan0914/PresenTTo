# 🎁 준비된 선물 (PresenTTo)

기념일, 받는 사람, 예산만 고르면 딱 맞는 선물 5개를 추천해 주는 Java Swing 프로그램입니다.

## 실행 방법
JDK 21 이상이 필요합니다.

```bash
javac -d out src/*.java
java -cp out Main
```

IntelliJ IDEA에서는 프로젝트를 열고 `Main`을 실행하면 됩니다.
창 크기는 1100×760으로, 13인치 노트북 화면에도 들어갑니다.

> 글꼴(Apple SD Gothic Neo)과 선물 그림(Apple Color Emoji)이 맥 기준이라 **macOS에서 실행**하는 것을 권장합니다.
> 윈도우에서는 선물 그림 이모지가 네모로 보일 수 있습니다.

## 사용 방법
1. **기념일**을 고릅니다. 처음에는 오늘에서 가장 가까운 기념일이 선택되어 있습니다.
2. **받는 사람**과 **예산**을 고릅니다. 예산은 칸에 직접 입력해도 됩니다.
3. **[선물 추천받기]**를 누르면 선물 카드 5장이 나옵니다. 다시 누르면 다른 선물이 나옵니다.
4. 마음에 드는 선물은 카드의 **하트**를 눌러 찜하고, **[찜 목록]**에서 모아 봅니다.

- 헤더는 코랄 → 복숭아색 그라데이션입니다.
- 줄마다 선택된 칩 색이 다릅니다: 기념일은 **코랄**, 받는 사람은 **보라**, 예산은 **청록**.
- 선택 안 된 칩은 테두리 없이 연한 회색이라 화면에 선이 적고 여백이 넉넉합니다.
- 칩, 버튼, 입력 칸은 모두 같은 둥글기(`RADIUS = 10`)를 씁니다.

## 기능

### 조건 고르기
| 항목 | 선택지 |
| --- | --- |
| 기념일 (14종) | 생일 · 커플 100일 · 커플 1주년 · 졸업·입학 · 승진·이직 · 설날 · 발렌타인데이 · 화이트데이 · 어린이날 · 어버이날 · 스승의날 · 수능 응원 · 빼빼로데이 · 크리스마스 |
| 받는 사람 (10종) | 친구 · 연인 · 썸 상대 · 부모님 · 조부모님 · 형제자매 · 조카 · 선후배 · 직장 동료 · 선생님 |
| 예산 | 1만원 이하 · 3만원 이하 · 5만원 이하 · 상관없음 · 직접 입력 |

- 기념일 칩 아래에 날짜와 D-day가 나옵니다. 예: `12월 25일 · D-37`
  - 생일, 설날처럼 날짜가 사람이나 해마다 다른 기념일은 안내 글자만 나옵니다. 예: `사람마다 달라요`
- 예산은 `25000`, `25,000원`, `3만`, `2만5000`처럼 입력할 수 있습니다.
  - 숫자가 아니거나, 0 이하이거나, 1억을 넘으면 빨간 글씨로 이유를 알려 주고 카드를 비웁니다.

### 추천 결과
- 선물 89종 중에서 최대 5개를 추천합니다.
- 카드 한 장에는 다음이 나옵니다.
  - 위쪽 그림 영역: 선물 종류 색 그라데이션, **선물마다 다른 그림(이모지, 예: 🎂 💐 ☕ 🎡)**, 종류 태그, 찜하기 하트
  - 아래쪽: 이름, 추천 이유, 설명, 가격
  - 가격은 종류 색으로, 쉼표를 넣어 `25,000원`처럼 보여 줍니다.
- **추천 이유** 예시: `연인 · 생일에 딱 맞아요`
- 기념일에 딱 맞는 선물이 5개가 안 되면 받는 사람에게 어울리는 다른 선물로 채웁니다. 이런 카드는 회색이고 **"이런 것도 있어요"** 태그가 붙습니다.
- 정렬은 **랜덤 / 가격 낮은 순 / 가격 높은 순** 중에서 고르고, 누르면 바로 다시 정렬됩니다.
- 선생님께는 청탁금지법을 고려해 0원짜리 마음 선물만 추천합니다.

### 선물 종류
| 종류 (태그) | 카드 색 | 개수 | 예시 |
| --- | --- | --- | --- |
| 일반 선물 | 빨강 | 53 | 핸드크림, 텀블러, 꽃다발, 손목시계, 명함 지갑 |
| 마음 선물 | 초록 | 15 | 손편지, 롤링페이퍼, 감사 영상 편지, 직접 만든 도시락 |
| 모바일 선물 | 파랑 | 11 | 카페 쿠폰, 케이크 기프티콘, 백화점 상품권 |
| 체험 선물 | 보라 | 10 | 방탈출 카페, 향수 만들기 공방, 놀이공원 자유이용권 |

### 찜 목록
- 카드의 하트를 누르면 찜하고, 다시 누르면 찜이 취소됩니다.
- [♥ 찜 목록 (n)]을 누르면 찜한 선물(그림 포함), 총 개수, 총액이 나오고 [빼기]로 하나씩 뺄 수 있습니다.
- 찜 목록은 프로그램을 끄면 사라집니다.

## 추천 방식
`GiftRecommender.recommend()`가 다음 순서로 선물을 고릅니다.

1. 예산을 넘거나 받는 사람에게 맞지 않는 선물은 뺍니다.
2. 남은 선물을 두 그룹으로 나눕니다.
   - **1순위**: 고른 기념일에 맞는 선물
   - **2순위**: 기념일은 다르지만 받는 사람과 예산이 맞는 선물
3. 그룹 안에서 정렬 방법(랜덤 / 가격순)대로 정렬합니다.
4. 1순위부터 앞에서 5개를 고릅니다. 개수는 `GiftRecommender.COUNT`로 정합니다.

## 클래스 구조

```
Gift (일반 선물)                   implements Comparable<Gift>
 ├─ HandmadeGift   (마음 선물)
 ├─ GifticonGift   (모바일 선물)
 └─ ExperienceGift (체험 선물)

Anniversary (추상 클래스)
 ├─ ValentinesDay, WhiteDay, ChildrensDay, ParentsDay,
 │  TeachersDay, PeperoDay, Christmas        (날짜가 정해진 기념일)
 └─ FlexibleAnniversary (추상 클래스)       (날짜가 다른 기념일)
     └─ Birthday, Couple100Days, CoupleAnniversary,
        Graduation, Promotion, LunarNewYear, ExamDay

Exception
 └─ BudgetException
```

| 클래스 | 설명 |
| --- | --- |
| `Main` | 프로그램 시작점이자 화면입니다. `JFrame`을 상속하고 `ActionListener`를 구현합니다. 아래 화면 부품 클래스도 안에 있습니다. |
| `GiftRecommender` | 선물 89종 목록을 가지고 있고, 조건에 맞는 선물을 골라 정렬합니다. |
| `Gift` | 선물 한 개의 정보(그림 이모지, 이름, 가격, 설명, 어울리는 기념일과 받는 사람)를 담습니다. 추천 이유, 태그, 카드 색을 알려 줍니다. |
| `HandmadeGift` | 0원짜리 마음 선물입니다. 가격 글자, 태그, 색을 오버라이딩합니다. |
| `GifticonGift` | 모바일 선물입니다. `super.getPriceText()` 뒤에 "바로 전송"을 붙입니다. |
| `ExperienceGift` | 체험 선물입니다. 태그와 색만 오버라이딩하고 가격 글자는 부모 것을 그대로 씁니다. |
| `Anniversary` | 기념일 추상 클래스입니다. 이름, 날짜, D-day 계산, 응원 문구(추상 메소드)를 가집니다. |
| `FlexibleAnniversary` | 날짜가 다른 기념일의 중간 부모 클래스입니다. D-day를 계산하지 않습니다. |
| `Anniversaries` | 기념일 14종을 만들어 `Anniversary[]`로 돌려줍니다. 각 기념일 자식 클래스도 이 파일에 있습니다. |
| `Wishlist` | 찜한 선물 목록입니다. 중복을 막고 총액을 계산합니다. |
| `BudgetException` | 예산을 잘못 입력했을 때 던지는 직접 만든 예외입니다. |

### 화면 부품 (`Main` 안의 클래스)
Swing 기본 부품을 상속하고 `paintComponent()`를 오버라이딩해서 직접 그렸습니다.

| 클래스 | 상속 | 역할 |
| --- | --- | --- |
| `Header` | `JPanel` | 맨 위 그라데이션 제목 띠 |
| `RoundPanel` | `JPanel` | 둥근 상자. 조건 상자, 카드, 태그, 정렬 묶음에 씁니다. |
| `GradientPanel` | `JPanel` | 둥근 그라데이션 상자. 카드 위쪽 그림 영역에 씁니다. |
| `DashedCard` | `JPanel` | 추천받기 전 점선 빈 카드 |
| `RoundButton` | `JButton` | 둥근 버튼 (찜 목록, 추천, 빼기) |
| `Chip` | `JToggleButton` | 선택 칩. 줄마다 선택 색이 다르고, 날짜를 아래에 보여 주는 두 줄 칩과 정렬용 세그먼트 모양도 됩니다. |
| `BudgetField` | `JTextField` | 예산 입력 칸. "직접 입력" 안내 글자, "원" 글자, 오류일 때 빨간 테두리 |

| `EmojiPicture` | `JComponent` | 선물 그림(이모지). 맥 자바는 100px보다 큰 컬러 이모지를 못 그려서, 96px 그림으로 한 번 만든 뒤 크기를 바꿔 그립니다. (레티나 화면 대응) |

## 객체지향 개념이 쓰인 곳
| 개념 | 어디에 |
| --- | --- |
| **캡슐화** | `Gift`, `Wishlist`의 필드는 모두 `private`이고 getter와 메소드로만 다룹니다. `Wishlist.getGifts()`는 복사본을 돌려줍니다. |
| **상속** | `Gift`를 상속한 선물 3종, `Anniversary` → `FlexibleAnniversary` → `Birthday`의 3단계 상속, `Main extends JFrame`, `BudgetException extends Exception` |
| **추상 클래스** | `Anniversary`, `FlexibleAnniversary`. `getMessage()`는 추상 메소드라 자식이 꼭 구현합니다. |
| **오버라이딩** | 선물 종류마다 `getTag()`, `getColor()`, `getPriceText()`를 다르게 구현합니다. 기념일마다 `getMessage()`를 다르게 구현합니다. 화면 부품은 `paintComponent()`를 오버라이딩해서 직접 그립니다. |
| **다형성** | `Main`은 `Gift`와 `Anniversary` 타입으로만 다룹니다. if문 없이 `gift.getColor()`나 `anniversary.getMessage()`를 부르면 객체에 맞는 결과가 나옵니다. |
| **인터페이스** | `ActionListener`로 버튼 클릭을 처리하고, `Comparable<Gift>`로 가격순 정렬을 합니다. |
| **예외 처리** | `parseBudget()`이 `BudgetException`을 던지고, `recommend()`가 `try-catch`로 받아 화면에 이유를 보여 줍니다. |
