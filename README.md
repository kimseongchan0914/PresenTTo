# 우리집 반려식물

선인장, 몬스테라, 해바라기 중 하나를 골라 이름을 지어 주고 꽃이 필 때까지 키우는 Java Swing 프로그램입니다.
순수 자바와 Swing만 사용했고, 이미지 파일이나 이모지 없이 그림을 모두 Graphics2D로 직접 그립니다.

## 실행 방법
JDK 21이 필요합니다. IntelliJ에서 프로젝트를 열고 `Main`을 실행하면 됩니다.

```bash
javac -d out src/*.java
java -cp out Main
```

> 한글 글꼴로 맥의 "Apple SD Gothic Neo"를 씁니다. 그래서 macOS에서 실행하는 것을 권장합니다.

## 사용 방법
1. 식물 종류를 고르고 이름을 지어 줍니다. 이름을 비워 두면 "초록이"가 됩니다.
   저장된 식물이 있으면 "이어서 키울까요?"를 먼저 묻습니다.
2. [물 주기] [햇빛 쬐기] [영양제] [하루 보내기] 버튼으로 돌봅니다.
3. 하루가 지나면 수분과 햇빛이 줄어듭니다. 알맞은 범위면 건강이 +10, 아니면 건강이 내려갑니다.
4. 하루가 끝났을 때 건강이 60 이상이면 "건강한 날"이 1 늘어납니다. 건강한 날 3일마다 한 단계 자랍니다.
   씨앗 → 새싹 → 줄기 → 꽃 (잘 키우면 10일째에 꽃이 핍니다)
5. 꽃이 피면 "키우기 성공!" 메시지가 나옵니다.
6. 건강이 0이 되면 "시들었어요..." 메시지가 나오고 처음부터 다시 시작합니다.

버튼을 누를 때마다 상태가 `plant.txt`에 자동으로 저장됩니다.

## 식물별 성격 (숫자)
모든 식물이 같은 것: 처음 값은 수분 50 / 햇빛 50 / 건강 60이고, 영양제는 건강 +10입니다.

| | 선인장 | 몬스테라 | 해바라기 |
|---|---|---|---|
| 물 주기 | 수분 +20, **수분 60 이상이면 건강 -10** | 수분 **+30** | 수분 +20 |
| 햇빛 쬐기 | 햇빛 +20 | 햇빛 +20, **햇빛 70 이상이면 건강 -10** | 햇빛 **+30** |
| 하루에 줄어드는 양 | 수분 **-5** / 햇빛 -15 | 수분 -20 / 햇빛 -10 | 수분 -15 / 햇빛 -20 |
| 건강 +10 조건 | 수분 10~59, 햇빛 30 이상 | 수분 40 이상, 햇빛 20~69 | 햇빛 30 이상, 수분 30 이상 |
| 조건이 안 맞으면 | 건강 -10 | 건강 -10 | 건강 -10 (**햇빛 30 미만이면 -25**) |
| 대사 예시 | "물 그만 줘...!" | "앗 뜨거! 잎이 타요!" | "햇빛 좋다~" |
| 그림 | 하얀 가시가 있는 몸통, 팔, 분홍 꽃 | 구멍 뚫린 잎, 크림색 꽃 | 줄기와 잎, 노란 꽃 |

건강이 50 아래로 떨어지면 잎 색이 누렇게 변합니다.

## 객체 지향 포인트
| 개념 | 어디에 있나 |
|------|------|
| **캡슐화** | `Plant`의 변수(이름, 수분, 햇빛, 건강, 날짜, 건강한 날)가 모두 `private`입니다. getter / setter로만 접근하고, setter 안의 `limit()`가 값이 0~100을 벗어나지 않게 막습니다. |
| **상속** | `Cactus`, `Monstera`, `Sunflower`가 `extends Plant`입니다. 화면 쪽은 `Main extends JFrame`, `PlantView extends JPanel`, `RoundButton extends JButton`입니다. |
| **추상 클래스** | `abstract class Plant`의 `getKind()`, `getSpeech()`, `draw()`는 추상 메소드라서 자식 클래스가 반드시 만듭니다. |
| **오버라이딩** | 각 식물이 `nextDay()`를 바꾸고, 마지막에 `super.nextDay()`로 부모의 날짜 +1을 부릅니다. `water()`, `sunbathe()`도 성격에 맞게 바꿉니다. 오버라이딩한 메소드에는 모두 `@Override`가 붙어 있습니다. |
| **다형성** | `Main`의 `private Plant plant;` 변수 하나로 어떤 식물이든 `plant.water()`, `plant.nextDay()`처럼 똑같이 부릅니다. `PlantView`도 `plant.draw()` 한 줄로 종류에 맞는 그림을 그립니다. |
| **인터페이스** | `Main implements ActionListener`이고, 버튼 4개의 클릭을 `actionPerformed()`에서 처리합니다. |
| **파일 입출력 / 예외 처리** | `SaveManager`가 `PrintWriter`로 쓰고 `BufferedReader`로 읽습니다. 파일이 없거나 내용이 깨졌을 때 try-catch로 잡아서 새로 시작합니다. |

## 저장 파일 (plant.txt)
한 줄에 값 하나씩, 아래 순서로 저장합니다. 프로그램을 실행한 폴더에 만들어집니다.

```
선인장      ← 종류
뾰족이      ← 이름
45          ← 수분
35          ← 햇빛
70          ← 건강
2           ← 날짜
1           ← 건강한 날 (3일마다 한 단계 성장)
```
