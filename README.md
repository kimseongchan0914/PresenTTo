# 🎁 준비된 선물 (PresenTTo)

기념일, 받는 사람, 예산만 고르면 딱 맞는 선물 3개를 추천해 주는 Java Swing 프로그램입니다.

## 기능
- 기념일 선택: 생일 / 크리스마스 / 어버이날 / 빼빼로데이
- 받는 사람 선택: 친구 / 부모님 / 선생님 / 형제자매
- 예산 선택: 1만원 이하 / 3만원 이하 / 5만원 이하 / 상관없음
- 조건에 맞는 선물을 최대 3개 추천 (누를 때마다 다른 결과)
- 선생님께는 청탁금지법을 고려해 0원짜리 마음 선물만 추천

## 실행 방법
JDK 21 이상이 필요합니다.

```bash
javac -d out src/*.java
java -cp out Main
```

IntelliJ IDEA에서는 프로젝트를 열고 `Main`을 실행하면 됩니다.

## 클래스 구조
| 클래스 | 설명 |
| --- | --- |
| `Gift` | 선물 한 개의 정보 (캡슐화) |
| `HandmadeGift` | `Gift`를 상속한 0원짜리 마음 선물 (오버라이딩) |
| `Anniversary` | 기념일 추상 클래스 |
| `Anniversaries` | 생일 / 크리스마스 / 어버이날 / 빼빼로데이 (다형성) |
| `GiftRecommender` | 선물 목록과 추천 로직 |
| `Main` | Swing 화면과 버튼 처리 |
