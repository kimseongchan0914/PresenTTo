# 우리집 반려식물

선인장, 몬스테라, 해바라기 중 하나를 골라 이름을 지어 주고 꽃이 필 때까지 키우는 Java Swing 프로그램입니다.
순수 자바와 Swing만 사용했고, 이미지 파일 없이 그림을 모두 Graphics2D로 그립니다.

## 실행 방법
JDK 21이 필요합니다. IntelliJ에서 프로젝트를 열고 `Main`을 실행하면 됩니다.

```bash
javac -d out src/*.java
java -cp out Main
```

## 사용 방법
1. 식물 종류를 고르고 이름을 지어 줍니다. 저장된 식물이 있으면 이어서 키울지 먼저 묻습니다.
2. [물 주기] [햇빛 쬐기] [영양제] [하루 보내기] 버튼으로 돌봅니다. 영양제는 하루에 한 번만 줄 수 있습니다.
3. 하루가 지나면 수분과 햇빛이 줄어듭니다. 알맞은 범위면 건강이 오르고, 아니면 내려갑니다.
4. 건강 60 이상으로 3일을 보내면 한 단계 자랍니다: 씨앗 → 새싹 → 줄기 → 꽃 (잘 키우면 10일째에 꽃이 핍니다).
5. 건강이 0이 되면 시들어서 처음부터 다시 시작합니다.

| 식물 | 성격 |
|------|------|
| 선인장 | 물이 천천히 줄어듦. 수분 60 이상이면 오히려 건강이 떨어짐 |
| 몬스테라 | 물을 좋아함(한 번에 +30). 햇빛 70 이상이면 잎이 타서 건강이 떨어짐 |
| 해바라기 | 햇빛을 좋아함(한 번에 +30). 햇빛 30 미만이면 하루 지날 때 건강 -25 |

## 파일 구성
| 파일 | 역할 |
|------|------|
| `Main.java` | 창과 버튼 (JFrame 상속, ActionListener 구현) |
| `Plant.java` | 모든 식물의 추상 부모 클래스 (상태는 private, getter/setter) |
| `Cactus.java` / `Monstera.java` / `Sunflower.java` | 식물마다 다른 물 주기, 햇빛, 하루 보내기, 대사, 그림 |
| `PlantView.java` | 제목 띠, 화분, 말풍선, 게이지를 그리는 패널 |
| `RoundButton.java` | 마우스를 올리면 색이 바뀌는 둥근 버튼 |
| `SaveManager.java` | `plant.txt` 저장 / 불러오기 (try-catch) |
